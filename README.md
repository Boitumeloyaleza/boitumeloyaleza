# My Digital Resume

Create a polished, responsive personal portfolio website using the attached CV as the source of truth. Include home introduction, about, technical and soft skills, at least three project cards with descriptions and technologies, education, certifications, work experience where present, contact links for email/GitHub/LinkedIn, and a downloadable CV button using the uploaded file. Use professional, modern styling and ensure all CV content is accurate and editable.
